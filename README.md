# 小雅粘粘粘

小雅平台（`*.ai-augmented.com`）的答题和复习助手，在脚本猫（ScriptCat）或 Tampermonkey 里运行。

它做三件事：

- **做作业**：把题目整理成一段文字复制给 AI，把 AI 的回答粘贴回来，逐题保存到小雅。只保存，不替你交卷。
- **看成绩**：交卷后列出每道题的得分和对错，老师公开答案时一并显示。
- **总复习**：把一门课的作业、练习、测验一次导出成 PDF 或 DOC，带目录，考前直接翻。（v2.1 新增）

作者：[Qy](https://qyovo.tech/)　·　源码：[GitHub](https://github.com/Qyyer233/xiaoya-zhanzhanzhan)（Apache-2.0 许可）

## 安装

1. 给浏览器装上[脚本猫](https://scriptcat.org/)或 Tampermonkey。
2. 打开[脚本猫上的发布页](https://scriptcat.org/zh-CN/script-show-page/6638)，点「安装」。
3. 打开小雅。第一次会自动展开面板，先选一个界面风格：胶带是浅色，朱批是深色，之后随时能换。

## 怎么用

### 做作业

1. 进入作业或测验页面，等悬浮图标上出现题数。
2. 点「复制题目给 AI」，粘贴给 AI。题目里图片多的话，点「导出」里的「图文 PDF」，把 PDF 发给能读 PDF 的 AI。
3. 把 AI 的回答整段粘贴进面板。面板会马上标出认出了哪几题、缺哪几题、哪题格式不对。
4. 确认无误后点「保存作答记录」。全部存上会自动刷新页面；有没存上的题会列出来。
5. 自己再检查一遍，然后到小雅页面上交卷。脚本不会替你交。

### 看成绩

交卷后回到这份作业，面板左边会多出一栏：总分、每题的得分和对错，可以只看错题或待批改的题。老师公开了答案，标准答案也会显示。

### 总复习

1. 打开课程页面，展开面板，切到「总复习」。不在课程页面时，先在面板里选一门课。
2. 作业按章节列出来，默认勾好已经截止的，可以整章勾选。
3. 选「合成一份」或「每份单独」，选 PDF 或 DOC，点「导出」。

| | PDF | DOC |
| --- | --- | --- |
| 合成一份 | 一个文件，开头是目录，点目录跳到对应的作业，每份另起一页 | 同左，Word 和 WPS 都能打开、修改 |
| 每份单独 | 浏览器一份一份弹出保存窗口 | 打成一个压缩包 |

份数多时建议选「合成一份」。勾上「附正确答案」，答案可以跟在每道题下面，也可以集中放在每份的末尾。

### 导出当前这一份

在作业页面点面板底部的「导出」：可以导出不带 AI 提示词的 PDF（公式会渲染出来）或 DOC，也可以直接复制文本；课程名、作业名要不要印在开头可以选。

旁边的「图片」可以预览题目里的图片，单独复制某一张或它的链接。

## 答案从哪来

「附正确答案」只用两种来源，不会猜：

- 老师公开的标准答案。
- 老师没公开时，只用被平台判为正确的你自己的作答。

做错的、还没批改的，不会当成答案导出。

## 支持的题型

| 题型 | 粘贴答案并保存 | 导出、看成绩 |
| --- | --- | --- |
| 单选题、多选题、判断题 | 支持 | 支持 |
| 填空题 | 支持 | 支持 |
| 简答题 | 支持，答案可以多行 | 支持 |
| 匹配题 | 支持，一对一、一对多都行 | 支持 |
| 题组 | 支持，阅读材料和小题会展开 | 支持 |
| 附件题 | 跳过，不上传附件，也不提交空答案 | 只有题干 |
| 编程题 | 跳过，请在小雅页面上作答 | 题目、你写的代码、老师公开的参考答案 |
| 排序题 | 跳过，请在小雅页面上作答 | 只有题干 |

## AI 返回格式

复制出来的文字里已经写好了格式要求，AI 应该这样回答：

```text
1 => A
2 => A,C
3 => const | let
4 => 完整的简答题答案，可以多行
5 => A:a,d | B:b,c
```

- 单选题、判断题：一个大写字母；判断题也可以写「对」「错」。
- 多选题：多个字母，可以用逗号分隔。
- 填空题：多个空用 `|` 分隔。
- 简答题：题号后面的所有内容都会保存，支持多行。
- 匹配题：左侧用大写字母，右侧用小写字母。

题号可能和网页上显示的不同，保存时按题目本身对应，不会错位。

## 使用提示

- 导出 PDF 走的是浏览器的打印窗口，目标打印机要选「另存为 PDF」。这样存下来的文字可以复制和搜索，目录可以点；选「Microsoft Print to PDF」之类的虚拟打印机，目录就点不了。
- 导出的 DOC 在 Word 里点目录，要按住 Ctrl 再点。DOC 里的公式是 TeX 文本，不会渲染。
- 「每份单独」导出 PDF 时，中途不想导了，关掉打印窗口，或者在面板上点「停止」。
- 有的作业读不到（比如老师没开放查看），清单里那一行会写明原因，其余照常导出。没交卷的作业会标上「没有交卷」。
- 进行中的作业默认不勾，可以手动勾上；还没开始的不能导出。
- 面板里会显示脚本公告，有新版本时会提示。

## 权限和隐私

| 权限 | 用途 |
| --- | --- |
| `GM_setClipboard` | 复制题目、作业文本、图片链接和诊断日志 |
| `GM_xmlhttpRequest` | 读取题目图片和脚本公告 |
| `GM_getValue` / `GM_setValue` | 保存面板位置、风格、导出设置、课程名和诊断日志 |
| `GM_getResourceText` | 导出作业 PDF 时加载公式渲染库 MathJax |
| `unsafeWindow` | 读取小雅页面自己请求到的题目数据 |
| `*.ai-augmented.com` | 在小雅平台运行，保存作答记录，「总复习」读取课程的作业清单和题目 |
| `*.aliyuncs.com` | 读取题目图片 |
| `xiaoya.qyovo.com` | 读取脚本公告 |

- 平时脚本只读取页面自己请求到的题目数据。
- 打开「总复习」时才会读取这门课的作业清单，点「导出」时才会读取你勾选的那些作业。只读题目，不会替你开始作答。
- 只在你点「保存作答记录」时保存答案，不会自动交卷。
- 脚本只联系三个地方：小雅平台、小雅存图片的阿里云、读取公告的 `xiaoya.qyovo.com`。题目、答案和账号信息不会发到别处。

## 遇到问题

脚本会在本地记一份诊断日志，方便排查：

- **单击**面板标题旁边的版本号：复制最近的日志。
- **双击**版本号：下载完整的日志文件。

把日志发给作者就行。日志只存在你的浏览器里，不会上传；里面有课程名、作业名和操作记录，不含登录信息、姓名、题目和答案的内容。
