# 小雅粘粘粘

一个适用于小雅平台的 Tampermonkey / ScriptCat 用户脚本：提取任务题目、生成 AI 作答模板、保存作答记录，并查看提交结果。

作者：[Qy](https://qyovo.tech/)

## 功能介绍

- **复制题目给 AI**：自动读取当前任务的题干、选项、图片和数学公式，整理成带答题格式的文字，并附上课程名，一键复制。
- **粘贴答案，实时检查**：把 AI 的回答整段粘贴进来，面板会标出识别到哪些题、缺哪些题、哪题格式不对，保存前就能改。
- **保存作答记录**：按题目真实 ID 逐题保存，不会替你交卷。全部成功后自动刷新页面；有失败的题会列出来。
- **查看提交结果**：交卷后在面板左侧显示总分、每题得分和对错，可以只看错题或待批改的题；老师公开答案时显示标准答案。
- **导出**：
  - 图文 PDF：带图片，公式保留 TeX 文本，适合发给能读 PDF 的 AI。
  - 纯净作业：不含 AI 提示词，可导出 PDF（渲染数学公式）、DOC 或复制文本；可以选择是否附上正确答案。
- **题目图片**：预览题目里的图片，复制图片或图片链接。
- **两种风格**：胶带（浅色）和朱批（深色），第一次使用时选择，之后随时切换。
- **公告与更新提示**：面板里显示脚本公告；有新版本时提示。

## 支持题型

| 题型 | 支持情况 |
| --- | --- |
| 单选题 | 支持 |
| 多选题 | 支持 |
| 填空题 | 支持，多个空用 `\|` 分隔 |
| 判断题 | 支持，可写字母或「对 / 错」 |
| 简答题 | 支持多行答案 |
| 附件题 | 识别并跳过 |
| 题组 | 支持阅读材料和小题展开 |
| 匹配题 | 支持一对一和一对多 |

## 使用方法

1. 安装 Tampermonkey、ScriptCat 或其他兼容的用户脚本管理器。
2. 安装并启用「小雅粘粘粘」。第一次打开小雅页面时，面板会自动展开，先选一个风格。
3. 进入需要作答的作业或测验页面，等悬浮图标显示题数。
4. 点「复制题目给 AI」，把内容发给 AI。
5. 把 AI 的回答粘贴到面板的输入框，检查识别结果。
6. 点「保存作答记录」。

## AI 返回格式

复制的模板里已经写好了格式要求。AI 应该这样回答：

```text
1 => A
2 => A,C
3 => const | let
4 => 完整的简答题答案，可以多行
5 => A:a,d | B:b,c
```

- 单选题、判断题：一个大写字母；判断题也可以写「对」「错」。
- 多选题：多个字母，可以用逗号分隔。
- 填空题：多个空用 `|` 分隔。
- 简答题：题号后面的所有内容都会保存，支持多行。
- 匹配题：左侧用大写字母，右侧用小写字母。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `GM_setClipboard` | 复制题目、作业文本和图片链接 |
| `GM_xmlhttpRequest` | 读取题目图片和脚本公告 |
| `GM_getValue` / `GM_setValue` | 保存面板位置、风格、导出设置和课程名 |
| `GM_getResourceText` | 导出作业 PDF 时加载公式渲染库 MathJax |
| `unsafeWindow` | 读取小雅页面自己请求到的题目数据 |
| `*.ai-augmented.com` | 在小雅平台运行，保存作答记录 |
| `*.aliyuncs.com` | 读取题目图片 |
| `xiaoya.qyovo.com` | 读取脚本公告 |

脚本只读取页面已经请求到的题目数据，只在你点击「保存作答记录」时保存答案，不会自动交卷。

## 使用提示

- 进入任务页面后，等悬浮图标显示题数再操作。
- 题号可能和网页上显示的不同，保存时按题目本身对应，不会错位。
- 保存前请检查 AI 的答案内容。
- 附件题不会上传附件，也不会提交空答案。
- 「附正确答案」只使用平台公开的标准答案，或已被判为正确的作答，不会猜测。
- 导出 PDF 时，在打印窗口里选择「另存为 PDF」，文字可以复制和搜索。
